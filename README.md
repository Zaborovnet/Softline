# Softline
# Directory Quota Manager

Приложение для мониторинга директории с автоматическим управлением квотой дискового пространства. Разработано на C++ с использованием Qt.


## Особенности

- Мониторинг выбранной директории в реальном времени
- Автоматическое удаление старых файлов при превышении квоты
- Отображение содержимого директории с размерами файлов
- Настройка квоты в мегабайтах
- Работа в фоновом режиме с многопоточностью
